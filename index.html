About

I'm Precious Olayemi Awoyemi, a Computer Engineer from Ibadan, Nigeria. I spent the past year maintaining live Communications, Navigation and Surveillance systems at Nigeria's Airspace Management Agency, keeping mission-critical infrastructure online at 99% uptime under real operational pressure.

I'm now applying that same discipline to the cloud, building hands-on with AWS and working toward Cloud Practitioner certification. This site tracks that work.

Approach

Each project starts with the theory on AWS Skill Builder, then gets rebuilt hands-on through NextWork's guided labs, real AWS Console and CLI/CloudShell, real errors, real fixes. Every build is documented and pushed to GitHub as part of an ongoing AWS roadmap.

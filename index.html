About

I'm Precious, a Computer Engineer from Nigeria, building a career in cloud engineering with a focus on security. I work hands-on in AWS, from VPC networking and least-privilege IAM to encryption, secrets management and real-time security alerts.

Each project starts with theory on AWS Skill Builder, then gets rebuilt in the AWS Console and CLI through NextWork's guided labs, with real errors and real fixes. Every build is documented on GitHub. I'm now deepening the security side with ISC2 Certified in Cybersecurity training and projects on threat detection and compliance. Earlier work maintaining live aviation systems taught me to put reliability first.
